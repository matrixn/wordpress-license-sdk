# Zion WordPress License SDK

SDK PHP pentru integrarea pluginurilor WordPress cu Zion License Server.

## Instalare

```bash
composer require zion/wordpress-license-sdk
```

SDK-ul este inclus în arhiva finală a pluginului și folosește `productSlug` și
`productKey` ca identificatori publici ai produsului. Cheile de licență și
tokenurile de activare sunt gestionate separat de serverul Zion.

Versiunea curentă: **0.1.7**.
